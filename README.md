# Sunlife Traders LLP

Next.js + Payload CMS site for Sunlife Traders LLP.

```bash
npm install
npm run dev
```

- Site: [http://localhost:3001](http://localhost:3001)
- Admin: [http://localhost:3001/admin](http://localhost:3001/admin)

Create the first admin user at `/admin` on first launch. Copy, solutions, projects, testimonials, FAQs, and contact details are editable in Payload. Contact form submissions land in **Leads**.
